Você trabalha no repositório de um TCC sobre ORDEM DE LEITURA e LAYOUT de diários oficiais brasileiros (PDFs multicoluna). Escreva tudo em português.

REGRAS (valem sempre):
- Crie SOMENTE os arquivos novos pedidos na tarefa. NÃO edite arquivos existentes. NÃO grave nada sob data/ (somente leitura). NÃO edite COMUNICACAO_AGENTES.md. NÃO faça commit.
- NÃO use GPU: ela está ocupada por um treino. Qualquer modelo roda em CPU (device="cpu").
- data/labelstudio/ é dado de um projeto parceiro (Data Policy): uso interno, nunca publique nem copie para fora do repositório. Os JSON de export são grandes (até 47 MB): não tente ler o arquivo inteiro como texto; descubra a estrutura por código e escreva código defensivo (campos podem faltar).
- Python do projeto: venv/Scripts/python.exe (3.11, Windows), executado da raiz do repositório. Use só biblioteca padrão, numpy, scipy, PIL e matplotlib, mais os módulos do próprio repositório. Abra arquivos com encoding="utf-8".
- Todo número de relatório tem que sair da execução do script (o script escreve o relatório). Não invente números. Declare limitações e vieses com honestidade (em especial: n pequeno; anotação feita corrigindo uma pré-anotação = viés de ancoragem).
- Formato do export do Label Studio: lista de tarefas; cada tarefa tem "id", "data" (URLs) e "annotations" (lista). Cada anotação tem "completed_by", "was_cancelled" e "result" (lista). Em "result", uma caixa aparece como vários itens com o MESMO "id": type "rectangle" (geometria), type "labels" (value.labels = [classe], value.x/y/width/height em % da página, "origin" = manual | prediction | prediction-changed, original_width/original_height em px), type "textarea" (value.text = [transcrição]). Itens type "relation" (from_id, to_id, labels, direction) ligam caixas na ordem de leitura.
- Três "PDFs" de Minas Gerais em data/labelstudio/pdf/ (pastas terminadas em -MG) são envelopes de assinatura digital PKCS#7: o PDF de verdade vai do primeiro b"%PDF" até o último b"%%EOF" do arquivo. Extraia esse trecho para um arquivo temporário sob resultados/ antes de abrir. Os outros PDFs abrem direto, mesmo os que terminam com bytes zerados.
- Não conte com rede: não instale pacotes nem baixe modelos. Já estão no ambiente: pdfplumber, PyMuPDF 1.28 (import pymupdf), ultralytics, transformers, torch (use CPU). Modelos de terceiros já baixados ficam em models/terceiros/.
- Esta máquina pode cair no meio do trabalho: grave caches e resultados intermediários sob resultados/ para a execução poder ser retomada sem refazer tudo, e escreva o relatório assim que tiver números.
- As 16 classes do guia e os mapeamentos para 9 e 3 classes estão em src/data/taxonomia_layout.py. Regra das 3 classes: table -> tabela; figure, chart, heading -> imagem; unknown fica de fora; o resto -> texto.
